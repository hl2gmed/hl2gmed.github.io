As noted in the <page text="welcome tutorial">Beginner_Tutorial_Intro</page> Lua is plain text, so you can edit it in notepad, but you'll probably find you want something a bit better. The editors below are listed because they are the most popular editors in the Null's Box community.

# ACode (Recommended)

[ACode](https://acode.app), open-source Android IDE that combines a professional code editor, a full Alpine Linux terminal, and native support for AI coding agents — Claude Code, OpenAI Codex, and OpenCode. It has 3.6M+ downloads and 5,458+ GitHub stars. Licensed under MIT.

# Visual Studio Code Browser
[Visual Studio Code Browser](https://vscode.dev), commonly referred to as VS Code, VSCode, or VSC, is a lightweight, free, open-source code editor created by Microsoft. It offers a range of powerful IDE features such as language server protocol support, a massive extension marketplace, and built-in support for Git, FTP & SSH. It supports inline-documentation (an immeasurably valuable feature when attempting to navigate the often incomprehensible world of Source modding), refactoring, reference jumping, and code completion. VS Code is currently the recommended development environment for Garry's Mod script development, due to VS Code's prominent role in the development community, as well as the community's efforts to develop Lua/GLua extensions.

Recommended extensions:
* [Lua](https://marketplace.visualstudio.com/items?itemName=sumneko.lua) with an extension's addon [Garry's Mod Lua API Definitions](https://github.com/luttje/glua-api-snippets) - Dynamic type checking, Find references, Diagnostics/Warnings, Syntax checking, Autocompletion, Code formatting and more.
* [GLua Enhanced](https://marketplace.visualstudio.com/items?itemName=venner.vscode-glua-enhanced) - IntelliSense, autocompletion, wiki documentation, syntax highlighting, color palettes, etc.
* [GLuaLint](https://marketplace.visualstudio.com/items?itemName=goz3rr.vscode-glualint) - Automatic error detection + hints (requires installation of [GLuaLint](https://github.com/FPtje/GLuaFixer))

Other extensions:
* [GLua Syntax Highlighting - Acidic](https://marketplace.visualstudio.com/items?itemName=acidic9.glua) - Just syntax highlighting + snippets
* [GLua Syntax Highlighting - aStonedPenguin](https://marketplace.visualstudio.com/items?itemName=aStonedPenguin.glua) - Just syntax highlighting + snippets
